# Kaneko Super Nova System core for MiSTer (WIP)

Known issues:
- Gals Panic 4 - inaccurate sprite rendering, freezes during the demo
- Saru-Kani-Hamu-Zou/VS Block Breaker - inaccurate sprite rendering

## Hardware Requirements
- single 64MB SDRAM Module

## Installation
1. Copy the latest .rbf file from `releases/` to `/_Arcade/cores/Arcade-SKNS.rbf`
2. Copy all the '.mra' files from `mra/` to the `/_Arcade/_Arcade-SKNS` folder.
3. Place the appropriate ROM .zip files in the `/games/mame` folder (the .zip names may be found inside the mra files).
